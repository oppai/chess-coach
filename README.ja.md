# Chess Coach

盤面で指す。チャットで学ぶ。

Hermes Desktopの右パネルで使うチェス練習プラグインです。初期言語は英語。パネル上部から日本語に切り替えられ、選択は端末に保存されます。

## 使える機能

- **1〜4手詰め**：検証済み14局面（7種類と左右反転版）。正誤判定、相手の応手、ヒントをローカル処理します。誤答では盤面を変更しません。
- **Hermesとの対戦**：白／黒、平手／ポーン／ナイト／ルーク／クイーン落ちを選択。相手側から駒を取り除きます。
- 駒と移動先のクリック、昇格先の選択、盤面反転、待った、最初から再挑戦、履歴から再開。
- 棋譜・PGNの表示。必要なときだけチャットに局面解説を依頼できます。

「1手」は自分の着手1回を意味します。4手詰めでは途中に相手の応手が入ります。

## LLMを待たない盤面

詰めチェスの開始・着手・判定・応手・ヒント・待った・再挑戦・PGN表示はLLMを呼びません。通常対戦でも自分の手を先に保存・表示し、相手の着手が必要なときだけHermesに1回依頼します。解説はボタンを押したときだけ依頼します。

相手から応答がない場合は、チャットを確認して「Hermesに指してもらう」から再試行できます。自動で繰り返し送信はしません。LLMの利用制限中でも、Hermesゲートウェイが動いていれば詰めチェスを練習できます。

## 導入・更新

フォルダを `~/.hermes/plugins/chess-coach` に置き、`hermes plugins enable chess-coach` を実行します。DesktopのCapabilities → PluginsでChess Coachを有効化してください。

更新後はゲートウェイを再起動し、コマンドパレットから「Reload desktop plugins」を実行します。

既存の対局は初回起動時にSQLiteへ移行します。対局ID・開始局面・棋譜を保持し、旧データファイルも残します。新しい正本はプロファイル内の `plugin-data/chess-coach/coach.sqlite3` です。

## 対応範囲

任意局面の詰み探索は1〜4手に対応しますが、計算量の多い局面は「検証未完了」を返します。詰みなしと断定しません。数値評価・自動悪手検出・正式な棋力認定はありません。定石や戦略の体系的な指導は今後の拡張対象です。

開発・テスト方法は [English README](README.md) を参照してください。
